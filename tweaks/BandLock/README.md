# BandLock Global

BandLock is a jailbreak app for manually controlling supported LTE/4G and 5G network modes and bands on iPhone.

## Features

- Manual LTE band selection
- 5G NR selection where supported by the modem
- Auto, 2G, 3G, 4G and 5G network modes
- Control Center module for quick mode switching
- Offline country profiles for compatible LTE/5G bands
- FDD / TDD / SDL band information
- Field Test access
- Restore previous or supported band selections
- In-app language selector
- Diagnostic logs

Country profiles only prepare a selection for review. They do not change modem settings automatically.

## Compatibility

Current public version: **1.3**

- **RootHide:** iOS 15–17 — `iphoneos-arm64e`
- **Dopamine rootless:** iOS 15–18 — `iphoneos-arm64`
- **Rootful:** iOS 15–16 — `iphoneos-arm`

Support on newer iOS versions and different devices can vary because BandLock relies on private CoreTelephony/CommCenter behavior.

The RootHide build has been tested on an iPhone XS running iOS 16.3.1. Other combinations benefit from community testing.
