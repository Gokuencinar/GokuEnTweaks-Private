# BandLock 1.0 — Rootful

This target builds BandLock 1.0 for classic **rootful iOS 16 jailbreaks**.

## Packaging

- Package: `com.gokuencinar.bandlock.rootful`
- Debian architecture: `iphoneos-arm`
- Binary architecture: `arm64` only (A8–A11-class rootful hardware)
- Application: `/Applications/BandLock.app`
- Daemon: `/usr/libexec/BandLockDaemon`
- LaunchDaemon: `/Library/LaunchDaemons/com.gokuencinar.bandlockd.rootful.plist`
- IPC socket: `/tmp/com.gokuencinar.bandlockd.rootful.sock`
- Field Test bridge: classic rootful MobileSubstrate/ElleKit injection path generated by Theos

The target intentionally does **not** set `THEOS_PACKAGE_SCHEME=rootless` and does not use RootHide/libroothide.

## Shared source

To avoid maintaining three copies of BandLock, the rootful target builds the normal Dopamine source tree with `BL_VARIANT_ROOTFUL=1`. That compile-time switch changes only the variant metadata and daemon socket. All UI, LTE/4G, 5G NR, country data, localization, Field Test and modem logic remain shared.

## Compatibility

The target is intended for iOS 16 rootful environments such as palera1n full-root on supported arm64 devices. Rootful-capable iOS 16 hardware is pre-5G, so LTE/4G can be tested physically there while the 5G controls remain present for source parity.

This variant must be validated on real rootful hardware before it is added to the public APT index.
